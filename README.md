# Inventory & IT Asset Control Toolkit

Python project that generates a professional Excel workbook for **inventory optimization** and **IT asset lifecycle management** interview demos.

All sample data is fictional.

## Quick Start

```bash
cd inventory-it-asset-toolkit
pip install -r requirements.txt
./build.sh          # macOS / Linux  (or: build.bat on Windows)
```

Equivalent: `python src/main.py` from the project root.

Output: `inventory-it-asset-toolkit/dist/Inventory_IT_Asset_Control_Toolkit.xlsx`
